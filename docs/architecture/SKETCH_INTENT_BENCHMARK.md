# Sketch intent resolver - benchmark report

Generated by `services/sketch_intent/bench/benchmark.py` (resolver `sketch-intent-0.1.0`, default parameters, tolerance 2.0 px). Deterministic; re-run to reproduce.

**Everything below except the washer section is synthetic.** GT discrepancy is measured against exact synthetic geometry and says how far the *proposal* is from the shape that generated the contour. It is not a statement about the accuracy of any camera, scale, or real part. Residuals inside proposals are fit diagnostics, not accuracy.
