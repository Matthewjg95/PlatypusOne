# Bench fixtures (printable)

Small printable fixtures for checking parts against the enclosure design before a
full print. Generators write binary STL with no dependencies beyond Python.

| Script | Prints | Status |
|---|---|---|
| `unoq_test_stand.py OUT_DIR` | UNO Q hole-pattern stands: flipped (component side down on 11 mm posts, the enclosure mounting) and upright (5 mm posts) | Flipped stand fit-checked 2026-11-01; see the script header for the header-side post flat |

The earlier enclosure mock-ups (display dummies, open-top device tray v1–v5) are
archived under tag `archive/claude/enclosure-mockups` (see [ARCHIVE.md](../../ARCHIVE.md));
the Fusion model is now the enclosure's source of truth.
